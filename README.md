# Noelia Irigoyen Propiedades

Sitio web de la inmobiliaria. Esta primera etapa es solo el inicio visual, para validar el diseño.

## Cómo verlo en local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

Nombre comercial, contactos y enlaces están en `src/config/site.ts`. Las propiedades de demostración están en `src/data/properties.ts`.
